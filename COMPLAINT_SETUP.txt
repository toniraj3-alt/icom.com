ICOM COUNT COMPLAINT PORTAL SETUP

The page validates all required fields, requires a machine image, generates a complaint number in the format AA123456, and posts the complaint to /api/complaints.

For real automatic email delivery to icomcount@outlook.com, the included Node.js backend must be deployed on a server and connected to an SMTP provider/account.

1. Install Node.js.
2. In this folder run: npm install
3. Set SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS and MAIL_FROM.
4. Run: npm start
5. Open: http://localhost:3000/complaint.html

IMPORTANT:
- The 2-letter + 6-digit number is generated by the browser in this starter version.
- For guaranteed globally unique complaint numbers across all customers, production should generate the number on the server and store it in a database.
- The destination email is fixed in server.js as icomcount@outlook.com.
- Do not put an email password directly in HTML/JavaScript. Use server environment variables.
